# 食事記録アプリ PoC計画

## 1. 目的
フロー・アーキテクチャの前提が成立するかを、アプリを作る前に確認する。結果によっては「Aは外す」「Cは参考値扱いにする」といったフローの見直しが起こり得るため、技術スタックやDB設計より先に実施する。

## 2. 進め方
- **アプリは作らない**。PC上の簡易スクリプト(Python等)と、手元の画像・バーコード番号で検証する
- 画像は実際にスマホで撮ったものを使う(ネットで拾った綺麗な画像だと実態とずれるため)
- 下記の判定基準は目安であり、用途に合わせて調整する

## 3. 検証項目

### PoC-1: Open Food Facts(方式A)

| 項目 | 内容 |
|---|---|
| 仮説 | 日本の市販品が十分な割合でヒットし、カロリー・PFCが揃っている |
| サンプル | 普段買う商品30点前後(コンビニ・スーパー、飲料・パン・弁当・菓子など種類を散らす) |
| 計測 | ①ヒット率 ②ヒットした中でカロリー・P・F・Cがすべて揃う割合 ③パッケージ表示との一致度 ④値の基準が100gあたりか1食あたりか |
| 目安 | ヒット率50%以上で実用的、20%未満ならAの価値は低い |

※ ④は特に重要。現仕様は「取得した値をそのまま記録する」ため、100g基準のまま記録されると実際の摂取量とずれる。

### PoC-2: 栄養成分表示OCR(方式B)

| 項目 | 内容 |
|---|---|
| 仮説 | Geminiで栄養成分表示を高精度に構造化できる |
| サンプル | 栄養成分表示の写真20枚前後(正面・斜め・光の反射・曲面・小さい文字・「100g当たり」と「1食当たり」の混在など、条件を散らす) |
| 計測 | 項目ごとの正答率(カロリー・P・F・C)、基準量の読み取り、誤読パターン |
| 目安 | カロリー・PFCの正答率90%以上 |
| 副産物 | プロンプトと出力スキーマ(JSON)の原案 |

### PoC-3: 写真AI推定(方式C)

| 項目 | 内容 |
|---|---|
| 仮説 | 推定値が「修正前提の叩き台」として使える精度にある |
| サンプル | 正解カロリーが分かる料理20〜30点(栄養表示付きの弁当・総菜、重さを量った自炊など) |
| 計測 | カロリー・PFCの誤差率、料理名の妥当性、同じ写真での出力のブレ(複数回実行) |
| 目安 | カロリー誤差の中央値が±20〜30%以内(常に修正前提のため、やや緩めの基準) |
| 副産物 | プロンプト原案、推定不能時の返し方 |

### PoC-4: 横断確認(Gemini API)

| 項目 | 内容 |
|---|---|
| モデル選定 | 精度・速度・コストのバランス(2〜3モデルを比較) |
| 応答時間 | 画像送信から結果取得まで(体感で許容できるか) |
| 画像サイズ | リサイズ・圧縮で精度と速度がどう変わるか |
| 無料枠・制限 | レート制限、1日の上限。個人利用で足りるか |
| データ取扱い | 無料枠での入力データの利用条件(食事写真を送ることの許容度) |
| 異常系 | 食べ物以外の画像、ぼやけ、通信エラー時の挙動 |

## 4. 実施順序と工数感

| 順 | 内容 | 目安 |
|---|---|---|
| 0 | サンプル収集(商品・栄養表示・料理の撮影)、APIキー準備 | 半日〜1日 |
| 1 | PoC-1 | 半日 |
| 2 | PoC-2 + PoC-4の一部(モデル比較) | 1日 |
| 3 | PoC-3 + PoC-4の残り | 1日 |
| 4 | 結果整理・判断 | 半日 |

合計3〜4日程度。PoC-1は独立して早く終わり、結果次第でフローに影響するため最初に実施する。

## 5. 結果に応じた判断

| 結果 | 対応 |
|---|---|
| Aのヒット率が低い | Aを外す、または他の商品DBを検討。B(OCR)を主軸にする |
| Aの値が100g基準中心 | 分量入力を、スコープ外からMVPに引き上げる |
| Bの精度が不十分 | 撮影ガイドの追加やプロンプト改善、確認画面での強調表示 |
| Cの誤差が大きい | 「目安値」と明示して残す、または外す |
| 無料枠の制限が厳しい | 利用回数の見積りを見直す、有料枠を検討 |

## 6. PoCに含めないもの
- UI・デザイン
- ローカルDB
- モバイルアプリのビルド
- 閲覧・編集・削除機能
- バーコードのオンデバイス読み取り(ML Kit/ZXing)※実績の多い技術のため。実機でのカメラ動作確認は、技術スタック決定後に小さく試す

## 7. 準備するもの
- Gemini APIキー
- サンプル(商品のバーコード番号、栄養成分表示の写真、料理写真と正解カロリー)

## 採番のルール

- 機能のまとまりごとに番号帯を分ける。採番済みの ID は変更・再利用しない（不要になったら「廃止」と書く）
- 詳細仕様は `features/F-xxx-<英語の短い名前>.md` に書き、要件ごとに `F-xxx-01` のような ID を振る（テストから参照する）
- 「区分」は MVP / 公開前（ストア公開までに必要）/ 次期 / 将来

| 番号帯 | まとまり |
|---|---|
| F-001〜009 | アカウント・認証 |
| F-010〜019 | 記録の入力（入力方式） |
| F-020〜029 | 確認・修正 |
| F-030〜039 | 記録の保存・閲覧・削除 |
| F-040〜059 | 次期以降の機能 |

## 一覧

### アカウント・認証

| ID | 機能 | 区分 | 概要 | 根拠 |
|---|---|---|---|---|
| F-001 | サインイン・サインアウト | MVP | Sign in with Apple と Google でサインインする。記録は利用者ごとに分ける | Q-17, [ADR-0006](../../adr/0006-auth-from-day-one.md) |
| F-002 | アカウントと記録の削除 | 公開前 | 利用者が自分のアカウントと記録をアプリ内で削除する（App Store の審査要件）。詳細は REQ-20 で決める | REQ-20 |

### 記録の入力

| ID | 機能 | 区分 | 概要 | 根拠 |
|---|---|---|---|---|
| F-010 | 入力方式の選択 | MVP | ホームで ①バーコード ②栄養成分表示 ③写真 ④手入力 を選ぶ | Q-03, Q-19 |
| F-011 | バーコード照合 | MVP | バーコードを読み、Open Food Facts から商品名・栄養値・内容量を取る。全部食べた量は「内容量 → 1食分の量（推定）→ 100g 当たり（内容量：不明）」の順で決める | [ADR-0009](../../adr/0009-barcode-adoption-and-net-content.md) |
| F-012 | 栄養成分表示の読み取り | MVP | 栄養成分表示を撮影し、Claude（Haiku 5.5）で基準量・栄養値・内容量を読む。複数列なら全列を返す | [ADR-0010](../../adr/0010-label-ocr-model-and-image-size.md), Q-26 |
| F-013 | 写真からの推定 | MVP | 料理を撮影し、Claude（Sonnet 5.5）で品目ごとの料理名・量・栄養値を推定する。推定値は目安値としてそのまま登録する | [ADR-0011](../../adr/0011-food-photo-model.md), Q-28 |
| F-014 | 手入力 | MVP | 食品名と kcal・P・F・C を利用者が入力する。①〜③で推定できない・不正確なときの最後の手段。Claude は使わない | [ADR-0012](../../adr/0012-manual-text-input.md) |

撮影した画像は推定に使った後すぐ破棄し、端末の外にもログにも残さない（[ADR-0004](../../adr/0004-no-image-retention.md)、F-012・F-013 共通）。

### 確認・修正

| ID | 機能 | 区分 | 概要 | 根拠 |
|---|---|---|---|---|
| F-020 | 確認・修正画面 | MVP | 取得・推定した結果を表示し、保存前に直す。表示: 値の出どころ、基準（1包装・1食（推定）・100g 当たりなど）、「内容量：不明」。修正: 分量のワンタップ選択（既定は全部、1個当たり・複数個入りは既定1個で個数を選ぶ）、複数列からの列の選択、料理名・品目の修正、バーコードから OCR への切り替え、食べた日時の変更（既定は記録した時刻、過去も可）。保存後の値の修正はしない | Q-14, Q-16, Q-26, Q-27, Q-31, Q-33, ADR-0009 |
| F-021 | 読み取れないときの案内 | MVP | エラーダイアログを出す。撮影する方式では「撮り直す」と撮り方の案内（正面から・近づけて）を置き、「入力方法の選択に戻る」も残す | Q-15, Q-25 |

### 記録の保存・閲覧・削除

| ID | 機能 | 区分 | 概要 | 根拠 |
|---|---|---|---|---|
| F-030 | 食事への追加・保存 | MVP | 確認した食品で食事（Meal）を作って保存する。保存済みの食事に後から食品を足せる。食事1件に食品 N件。食品ごとの値と食事の合計を持つ。食事区分は持たない | CLAUDE.md, REQ-06, REQ-07, Q-32 |
| F-031 | 日次合計と食事一覧 | MVP | 1日（4:00 区切り、日本時間）の kcal・P・F・C の合計と、その日の食事・食品の一覧を時刻順に見る | Q-09, Q-16, Q-33 |
| F-032 | 食事・食品の削除 | MVP | 食事単位・食品単位で削除する。食品が0件になった食事は自動で削除する | Q-16, Q-31 |

# ADR-0004: 撮影画像は保存しない

- ステータス: Accepted
- 日付: 2026-11-11
- 関連: Q-07, REQ-19, DAT-05, DAT-11, LLM-12, SEC-03

## 決定

バーコード・栄養成分表示・料理の撮影画像は、推定やデータ取得が終わったら（成功・失敗にかかわらず）すぐ破棄する。端末・バックエンドのどちらにも保存しない。

## 影響

- 画像ストレージは不要（DAT-11 は SKIP）。コストとプライバシーリスクが下がる。
- **バックエンドのログ・エラー報告にも画像（base64）を残さない**。ログに残すのはメタ情報（サイズ・トークン数・レイテンシ・モデルID・プロンプト版）とモデルの出力だけ。
- 推定の生出力（テキスト/JSON）は精度改善のため保存してよい（DAT-05）。
- 後から同じ画像で再推定することはできない。振り返りで写真を見る機能も作らない。
- 精度評価（eval）には、ユーザーの利用データではなく、自分で用意したサンプル（`poc/samples/`、Git 管理外）を使う。
- Anthropic への画像送信は避けられないため、公開時にはプライバシーポリシーへの記載と同意が必要（SEC-03）。

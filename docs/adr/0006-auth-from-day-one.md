# ADR-0006: 認証は最初から入れる（Sign in with Apple + Google）

- ステータス: Accepted（認証基盤の選択は Q-12 の結果に従う）
- 日付: 2026-11-11
- 関連: Q-17, AUT-01, AUT-02, AUT-03, ADR-0003

## 背景

Claude API はバックエンド経由で呼ぶ（ADR-0003）。認証がないと、推定 API を第三者に使われて費用が発生するおそれがある。また将来ストアで公開する予定がある。

## 決定

- 自分専用の段階（MVP）から認証を入れる。
- ログイン方法は **Sign in with Apple** と **Google** の2つ。iOS でソーシャルログインを提供する場合は Apple ログインがストア審査で求められるため、最初から両方用意する。
- メールアドレス＋パスワードのログインは作らない（パスワード管理の負担を避ける）。

## 影響

- 全 API でログイン済みかどうかを検証し、データはユーザー単位で分ける（AUT-05）。
- 認証基盤（Supabase Auth / Cognito など）はバックエンド構成の決定（Q-12）に合わせて選ぶ。
- アカウント削除フローも用意する（AUT-08、ストア審査の要件）。
